# Intro to Git: Homework 2

This repository is meant to simulate an *integration manager* workflow.

## Task

1. Explore the list of [open issues on this kanban board](https://github.com/orgs/intro-to-git/projects/3).

2. Choose an issue you want to complete and assign it to yourself.

3. **Fork** this project into your personal github space

4. Clone **your fork** of the repository to your computer

5. Create a feature branch for your issue

6. Write the code required to resolve the issue. The code should be placed in the `tasks/` directory

7. Push your feature branch and open a Pull Request to this repository

8. Make sure all check on your Pull Request are **passing**

9. Ask a fellow student to review your code (Everyone should review at least one Pull Request)

10. Submit a link to your Pull Request on Canvas

11. The instructor will also review all Pull Requests before grading and merging
